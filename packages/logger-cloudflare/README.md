# `@pegma/logger-cloudflare`

A Cloudflare Workers Logs implementation of the
[`@pegma/spine`](https://github.com/pegma-dev/spine) `Logger` port.

It emits JSON-friendly structured entries through the host's injected console
surface and introduces no Cloudflare runtime dependency.

See the repository
[README](https://github.com/pegma-dev/logger-adapters) and
[adapter design](https://github.com/pegma-dev/logger-adapters/blob/main/docs/CLOUDFLARE.md)
for usage and guarantees.
